# Tools

The 6 generic tools agents use. No named tools like `create_matter` — just 6 operations on any table.

- [Create](/tools/create.md) — INSERT into any table
- [Read](/tools/read.md) — SELECT from any table
- [Update](/tools/update.md) — UPDATE any table
- [Delete](/tools/delete.md) — SOFT DELETE from any table
- [Link](/tools/link.md) — INSERT/TOGGLE graph edge
- [Search](/tools/search.md) — VECTOR SEARCH in Turso memory
