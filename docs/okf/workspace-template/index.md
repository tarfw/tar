# Workspace Knowledge Bundle (Template)

Per-workspace OKF bundle. Each business gets their own copy of this template, filled with their specific knowledge. The agent reads this bundle to understand the business it's serving.

## Folder map

- [/business/](/business/index.md) — profile, team, channels
- [/products/](/products/index.md) — catalog, categories, suppliers
- [/policies/](/policies/index.md) — returns, delivery, payments
- [/workflows/](/workflows/index.md) — order flow, delivery flow, inventory flow
- [/reports/](/reports/index.md) — daily sales, stock valuation, tax summary
- [/macros/](/macros/index.md) — template replies for common messages
- [/reference/](/reference/index.md) — SKU codes, expense categories

See [log.md](/log.md) for the change history.
