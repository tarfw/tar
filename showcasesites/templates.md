### Universal Sections (Every Store Has These)

| Section | Purpose | AI Prompt Example |
|---------|---------|-------------------|
| **Announcement Bar** | Top bar with promo/shipping info | "add free shipping banner at top" |
| **Sticky Header** | Logo + nav + cart icon, sticks on scroll | "make header sticky with logo centered" |
| **Hero Banner** | Full-width image/video + headline + CTA | "big hero with store name and shop now button" |
| **Product Grid** | 2-4 column grid of product cards | "show all products in a 3-column grid" |
| **Product Carousel** | Horizontal scrollable product row | "add a featured products carousel" |
| **Footer** | Multi-column links, social, newsletter | "add footer with contact info and social links" |

### Design Patterns

| Pattern | How Top Stores Do It |
|---------|---------------------|
| **Color scheme** | 2-3 colors max. Neutral bg, 1 accent color |
| **Typography** | 1-2 fonts. Sans-serif for body, bold for headings |
| **Spacing** | Generous whitespace. 80-120px between sections |
| **Images** | High-quality product photos. Lifestyle + product shots |
| **Mobile-first** | 60%+ traffic is mobile. Design for phone first |
| **CTA buttons** | Large, high-contrast, clear action words |
| **Trust signals** | Reviews, press logos, money-back guarantee |
| **Urgency** | Countdown timers, "only X left", limited offers |

### SEO Requirements

| Element | Format | Example |
|---------|--------|---------|
| `<title>` | `{Store Name} — {Tagline}` | `SKIMS — Solutions For Every Body` |
| `<meta description>` | 150-160 chars, includes keywords | `Shop SKIMS shapewear, underwear...` |
| `<meta og:title>` | Same as title | Used for social sharing |
| `<meta og:image>` | 1200x630px logo/product image | Social share preview |
| `<meta og:description>` | Same as meta description | Social share preview |
| `JSON-LD` | Schema.org structured data | Organization, Product, BreadcrumbList |
| `<link rel="canonical">` | Self-referencing URL | Prevents duplicate content |
| `<hreflang>` | Language/region variants | `en-US`, `en-GB`, `fr-FR` |
| `<meta viewport>` | `width=device-width, initial-scale=1` | Mobile rendering |

### JSON-LD Structured Data (Critical for SEO)

```json
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Store Name",
  "url": "https://store.tarai.space",
  "logo": "https://store.tarai.space/logo.png",
  "sameAs": ["https://instagram.com/store"]
}
```

```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Pepsi 500ml",
  "image": "https://store.tarai.space/pepsi.jpg",

    "@type": "Offer",
    "price": "40",
    "priceCurrency": "INR",
    "availability": "https://schema.org/InStock"
  }
}
```

## AI Generation Quality Bar

| Metric | Target |
|--------|--------|
| Sections per homepage | 6-12 |
| Load time | < 2s (KV cached) |
| Mobile responsive | 100% |
| SEO score | 90+ (Lighthouse) |
| Accessibility | WCAG 2.1 AA |
| Image optimization | WebP, lazy-loaded |
| Font loading | Preloaded, FOUT-free |
| Color contrast | 4.5:1 minimum |

### Design Quality Checklist

- [ ] Hero has clear value proposition in < 5 words
- [ ] CTA buttons are large and high-contrast
- [ ] Product cards show image, title, price, rating
- [ ] Footer has contact info, social links, policies
- [ ] Mobile hamburger menu works
- [ ] Cart drawer slides in from right
- [ ] Images are optimized (WebP, lazy-loaded)
- [ ] Page has structured data (JSON-LD)
- [ ] Meta tags are complete (title, description, og:image)
- [ ] Color scheme is consistent (2-3 colors max)
- [ ] Typography is readable (16px+ body, clear hierarchy)
- [ ] Spacing is generous (80px+ between sections)
