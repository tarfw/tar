# Drinkpouch Aesthetic Rules

**Template**: `editorial-chalk`

## Aesthetic Goals
- 100% Anti-Slop.
- Ultra-premium, clean, and highly readable.
- Colors: Chalk background `#edebe4`, Deep Navy text `#01273e`, Pulse Blue accents `#000bfa`.
- Typography: Use Matter (sans), Auguste Serif (serif), Matter Mono (monospace).

## Component Rules
1. **Marquee Loop**: Used for top announcement bar and section dividers. Must scroll infinitely with no breaks.
2. **Badges**: Must use `backdrop-filter: blur(30px)`. Font must be uppercase Mono (`font-size: .6875rem`).
3. **Product Cards**: Images must sit in a container with `aspect-ratio: 1` or `cover`. Clean Add to Bag buttons.
4. **Hero Banner**: Split 2-column layout. Left text with large heading. Right image.
5. **Custom Cursor**: Inject a blue dot cursor for hover interactions.
6. **No Emojis**: Absolutely no emojis or generic stock vectors.
