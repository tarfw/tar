# Minimal Clean Design System (DESIGN.md)

## Brand Identity
- **Name**: Minimal Modern Clean
- **Vibe**: Tech-forward, clean slate backdrop, electric indigo CTA accents, modern Outfit headers.

## Color Palette
- **Background**: `#F8FAFC` (Light Slate Soft)
- **Surface**: `#FFFFFF` (Pure White)
- **Text**: `#0F172A` (Deep Slate)
- **Muted**: `#64748B` (Muted Slate)
- **Primary**: `#5E6AD2` (Electric Indigo)
- **Secondary**: `#0F172A` (Dark Accent)
- **Border**: `rgba(0, 0, 0, 0.08)`

## Typography
- **Heading Font**: `'Outfit', system-ui, sans-serif`
- **Body Font**: `'Inter', system-ui, sans-serif`
- **Heading Weight**: `700`
- **Body Weight**: `400`
- **Scale**:

  - H2: `2rem` (`32px`), line-height `1.3`
  - Body: `1rem` (`16px`), line-height `1.6`

## Radius & Borders

- **Border Radius Medium**: `12px`
